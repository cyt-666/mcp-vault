## 目的

承接[三组原文块实验](../completed/memory-block-grouping-experiment.md)：上一轮原文块由 Astra 指定行范围，三例有去重收益且未发现必要信息丢失，但不证明自动切块或难例安全。用户要求继续验证自动切块，以及顺序、例外和跨项目反例。

本轮交付自动 AST 切块的独立原型、三组真实笔记回归和三组合成困难对照的实际模型结果。原三案仅指定目标章节，章节内由程序自动选择结构边界；这仍不等于全库自动入选。合成项目和流程只作测试资料，不是用户实际政策。

## 约束与当前状态

依据 [产品要求](../../product-requirements.md)、[架构](../../architecture.md)、[记忆契约](../../memory-system.md)和[ADR-0033](../../adr/0033-source-preserving-memory-units.md)。当前正式服务仍使用整章节候选，不支持本轮跨来源组织。原型位于 Git 忽略的 `target/memory-block-grouping-experiment-20260910/` 独立工程，产品 crate、历史迁移和正式数据不修改。实现产品切换前仍需修订规范、ADR、迁移和完整纵向流程。

## 设计与范围

- 使用与仓库同版本的 comrak AST，从完整文件提取 paragraph、list、table、code、math、quote 等原文块；冒号导语与紧随的完整结构保守绑定，不按字符数或测试主题关键词截断。
- 保留精确 UTF-8 字节／行范围、来源哈希、frontmatter、标题和祖先引言。原文块与 context 分开统计，不能以复制整章到 context 掩盖遗漏或虚报压缩。
- 不同源身份即使文件字节相同，块编号也必须不同。完整文件 inventory 和所选章节块分别输出；章节选择默认 exact，任何未命中选择应在调用模型前失败。
- 原三案来源：Loss、StandardScaler、GPU 与相邻噪声结论。九篇合成笔记覆盖恢复动作顺序冲突、父引言例外／24 小时审计、项目专属规则与综合表桥接。
- 统一沿用上一轮分组 SYSTEM；预期文件不传给 MiMo。模型只提出分组、显示块和完整覆盖映射，不能写新正文。

## 风险

AST 只保证结构边界，不保证段落语义独立。代词、公式变量、前提与例外可能跨块；必须审查实际显示正文及 context 的完整意义。关系相似不能自动传递；不同项目的相同措辞不能掩盖不同范围或附加条件。归组边界问题、实际信息丢失、无收益和工程错误分别记录。
