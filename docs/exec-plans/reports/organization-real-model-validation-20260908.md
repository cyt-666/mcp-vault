# 记忆整理真实模型验证

日期：2026-09-08。关联 [ADR-0031](../../adr/0031-incremental-memory-organization.md)与[执行计划](../completed/organization-outcome-diagnostics.md)。

## 结论

已在真实本地服务中复现并修复一个候选发现缺陷：模型没有填写可选的“预期输出维度”时，即使当前记忆向量覆盖完整，整理也会跳过整个向量通道。修复后，从种子记忆当前 profile、精确输入对应的有效向量读取实际维度，向量候选进入真实 MiMo 判断。此结果确认本地代码缺陷，不能回溯证明生产旧 87 次请求的全部失败原因。

真实模型仍存在候选漏召回及完整等价判断风险。本报告不以队列完成、JSON 有效或条目数减少作为语义质量达标的证据。

## 实测范围

通过已有 MCP 连接只读导出 325 条单来源记忆和 27 篇来源笔记。将原始记忆文本、类型、有效期与来源文本导入隔离的本地 Vault；本地文件身份重新生成，MCP 未公开的内部提取元数据不猜测。没有启动或迁移原始 `data` 数据库，没有修改生产 Vault。

测试使用实际 `mcp-vault` 二进制和认证 Admin HTTP。判断模型为实际 `mimo-v2.5`；用户在本地管理页配置智谱 `embedding-3`，预期维度留空，实际返回 2048 维。付费调用由用户明确授权，仅显式手工运行，不进入 CI。

`crates/server/examples/live_memory_organization.rs` 提供以下重放模式，参数要求配置数据库副本、密钥文件路径、快照、新测试目录与服务二进制：

- `--run-authorized-live-test`：仅配置真实判断模型，验证词法候选路径。
- `--serve-for-configuration`：暂停整理并启动服务，由用户在 Admin 配置模型。
- `--run-authorized-live-hybrid-test`：复制选定模型配置，等待当前记忆实际向量覆盖完整后恢复整理。
- `--prepare-authorized-live-vectors`：只生成实际向量，整理保持暂停，不执行 MiMo 判断。

凭据通过 Auth 服务读取、在内存中解密并用新实例密钥重新加密；不输出凭据、Cookie 或密码。原始数据、内容审查及运行日志位于 Git 忽略目录 `target/memory-organization-validation/live-20260908/`。

## 候选覆盖与判断质量

中英文 KV Cache 控制对表达相同事实，实际余弦为 0.746789，低于既定 0.75 门槛，因此漏召回发生在模型判断之前。不能将该结果解释为模型拒绝等价。

进一步为仓库 `dedup-merge.json` 标注语料的 59 条不同原文生成真实向量，检查 60 个方向性关系。20 个等价方向全部超过 0.75，最低为 0.753816；30 个不同方向也全部超过 0.75。正反方向来自同一对文本，不是独立样本。该语料只能说明这些样例的覆盖，不能提供通用准确率。

对本轮原始 325 条实际记忆向量计算无向邻接对，得到下列范围。它不包含词法通道、前 8 个候选截断及来源资格过滤，因此不是实际模型请求预算。

| 余弦门槛 | 通过的无向对 | 涉及记忆数 |
| --- | --- | --- |
| 0.80 | 9 | 17 |
| 0.75 | 31 | 54 |
| 0.74 | 42 | 67 |
| 0.70 | 91 | 122 |
| 0.65 | 257 | 224 |

本轮保留 0.75：有限样本不足以确定新的通用门槛，降低门槛也不能修复等价判断。已知边界漏召回作为后续候选策略的验证样例保留。

真实全量运行中，一对关于程序设备使用的说明被模型判为等价，但其中一侧额外包含验证步骤。按“各自支持对方完整命题”的标准，该判断有误合并疑点，应作为质量失败样例，而非自动计入正确合并。来源贡献仍完整保留，但正式代表文本可能不再表达被吸收一侧的所有细节。当前结构校验只验证字段、关系枚举与候选编号，不能证明自然语言关系正确。
