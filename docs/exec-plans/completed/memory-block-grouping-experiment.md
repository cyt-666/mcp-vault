# 完整原文块组织与去冗余实验

创建与更新：2026-09-10。执行：Luna 编写实验工具并运行，Astra 冻结案例并审查。状态：三组真实模型可行性实验与逐项审查完成，本轮案例通过；未实施产品变更，不代表全量质量验收。

## 目的与用户可见结果

最初的 325 条原始贡献／27 篇笔记存在同篇重复、跨篇同义及部分重叠。前轮生成式整合丢失默认行为和顺序；v3 保留原文后又暴露误选与整章夹带。用户要求同时解决内容完整性和重复，不能把减少对象数量等同于减少重复文字。

本实验提供三组实际输出与原文对照，分别判断归组、去冗余、独有信息覆盖和来源准确性。实验输出不进入正式记忆。

## 约束与当前实现

遵循 [产品要求](../../product-requirements.md)、[架构](../../architecture.md)、[记忆契约](../../memory-system.md)、[ADR-0033](../../adr/0033-source-preserving-memory-units.md) 的来源、隔离、Provider、安全和恢复边界。[原始问题](../active/mcp-vault-automatic-memory-dedup-merge-execplan.md)与[真实整合失败](../reports/lossless-consolidation-validation-20260908.md)保留为历史证据。

当前 `crates/memory/src/units.rs` 只生成完整章节，`resolve_selection` 只消除父子原文范围重复；v3 不提供跨来源正式分组。当前产品契约仍禁止跨来源合并。下面的用户决定授权可行性实验，不代表代码已实现或现有契约已经更新；若实验支持实施，需要同时修订规范和 ADR，再设计迁移与完整纵向切片。

## 已确认的设计方向

- 候选允许完整原文块及同源非连续多块，程序提取正文，模型不改写。必要前提、范围、顺序、例外和验证步骤须保留。
- 个人学习成果可入选，未验证理解保留不确定性；无法确定是个人理解还是摘录时不自动归为个人成果。此项本轮不测试。
- 原始摘录按来源独立保存；正式记忆可以组织同一具体结论／流程的多个来源。不能仅凭主题相同，也不能按相似关系传递归组。
- 归组和去重分开评价：完整等价可选原文代表并保留来源；部分重叠不能丢独有内容，残留重复必须如实报告。
- 明确纠正关系与范围才可影响旧理解的默认召回；纠正来源删除后解除屏蔽。此项本轮不实现、不测试。

## 范围、风险与方法

冻结原库中《损失函数》、StandardScaler 双来源、GPU 双来源的完整句群／列表／公式／代码块；GPU 案例含同笔记相邻噪声结论作为不同主题负例。手工冻结范围只用于小样本控制，不证明自动切块／候选发现正确。模型只获得原文和统一协议，不获得人工预期。

每案例一次真实调用，共三次。使用独立隔离配置的生产 `ProviderService` 与结构化校验，不启动 HTTP、worker、embedding、overview 或正式记忆发布；不直接请求绕过 ProviderTransport。隔离 Provider 禁止传输重试。首次 Provider、schema 或引用结构错误停止，保留已完成结果，不追加修补或新付费轮次。

模型返回分组、显示块和被完整覆盖块的引用映射；工具验证编号闭合、唯一归属和无循环，复制原文构建实验视图。结构验证无法证明语义覆盖。Astra 按事前预期审查完整实际正文，不把模型自评当分数。
